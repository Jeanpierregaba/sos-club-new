# Club Santé SOS Docteur TV

Plateforme web des Clubs Santé : un site TanStack Start et une API FastAPI avec PostgreSQL.

Le produit est décrit dans [docs/PRD.md](docs/PRD.md), la technique dans
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) et l'avancement dans [TASKS.md](TASKS.md).

## Démarrer

### Site

Prérequis : Node.js et [Bun](https://bun.sh).

```bash
bun install
```

```bash
npm run dev
```

Voir [backend/README.md](backend/README.md).
